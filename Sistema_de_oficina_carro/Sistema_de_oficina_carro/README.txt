SISTEMA DE OFICINA DE CARROS - ATUALIZADO

Projeto Java puro, sem banco de dados e sem bibliotecas externas.

Principais recursos:
- Cadastro de clientes
- Cadastro de peças e controle de estoque
- Pesquisa de peças por nome ou código
- Ordem de serviço unindo cliente + veículo + serviços + peças
- Cálculo automático do total da ordem
- Listagem de clientes, peças e ordens

Estrutura:
src/com/oficina/Main.java
src/com/oficina/model/Cliente.java
src/com/oficina/model/Servico.java
src/com/oficina/model/Peca.java
src/com/oficina/model/OrdemServico.java
src/com/oficina/util/ValidadorCPF.java

Para executar no VS Code, abra a pasta do projeto e execute Main.java.
